# 소프트웨어공학 5조

## 공강메이트 (Gonggang Mate)

> 대학생의 공강 시간을 연결하는 활동·친구 매칭 서비스

## 프로젝트 소개

공강메이트는 대학생들의 시간표에서 발생하는 공강 시간을 활용할 수 있도록 도와주는 매칭 서비스입니다.

대학생들은 수업과 수업 사이에 공강이 생기지만, 함께 시간을 보낼 친구와 공강 시간이 맞지 않거나 짧고 애매한 공강 때문에 시간을 효율적으로 활용하지 못하는 경우가 많습니다.

공강메이트는 사용자의 시간표를 기반으로 공강 시간을 파악하고, 다른 사용자와 겹치는 공강 시간과 관심 활동을 비교하여 함께 시간을 보낼 수 있는 사용자를 찾아줍니다.

또한 공강 시간의 길이와 사용자의 관심사를 고려하여 공부, 식사, 운동, 산책, 카페 등의 활동을 추천함으로써 남는 공강 시간을 보다 유용하게 활용할 수 있도록 하는 것을 목표로 합니다.


## 주요 기능

### 시간표 및 공강 관리
- 사용자의 강의 시간표 등록
- 시간표를 기반으로 공강 시간 확인
- 요일별 공강 시간 관리

### 공강 매칭
- 다른 사용자와 겹치는 공강 시간 탐색
- 공통 공강 시간 계산
- 원하는 활동과 관심사를 고려한 사용자 매칭

### 활동 추천
- 공강 시간의 길이에 따른 활동 추천
- 사용자의 관심사를 반영한 활동 추천

예시:
- 30분 공강 → 산책, 카페
- 1시간 공강 → 식사
- 2시간 공강 → 스터디, 운동

### 매칭 및 활동 관리
- 원하는 공강 시간에 매칭 요청
- 매칭 수락 및 거절
- 성사된 매칭 및 활동 일정 확인


## 주요 사용자

공강 시간을 보다 효율적으로 활용하고 싶은 대학생을 주요 사용자로 합니다.

특히 다음과 같은 상황에서 활용할 수 있습니다.

- 공강 시간이 겹치는 친구를 찾고 싶은 경우
- 같이 식사하거나 공부할 사람을 찾고 싶은 경우
- 애매하게 남은 공강 시간에 무엇을 할지 고민되는 경우
- 새로운 사람과 관심사가 맞는 활동을 함께하고 싶은 경우


## 핵심 아이디어

공강메이트의 핵심은 단순한 시간표 공유가 아니라,

**공통 공강 시간 탐색 + 관심 활동 기반 매칭 + 공강 시간 활용 추천**

을 결합하여 대학생의 남는 시간을 실제 활동으로 연결하는 것입니다.


## 개발 목표

- 대학생의 공강 시간을 효과적으로 활용할 수 있는 서비스 구현
- 시간 구간 교집합을 이용한 공통 공강 탐색
- 사용자 조건 및 관심 활동을 고려한 매칭 기능 구현
- 4인 팀 협업을 통한 요구사항 분석, 설계, 구현 및 테스트 수행
